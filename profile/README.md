## 🚀 Overview
Affinity Suite for Windows unites three creative disciplines — raster photo editing, precise vector illustration, and multi-page document layout — inside a single, coordinated toolset. Instead of switching between separate programs, you can retouch an image, draw scalable artwork, and assemble a finished document without leaving your workflow. Built by Serif and now part of Canva, this affinity creative suite is designed for both seasoned professionals and creatives who want one dependable set of tools for everyday design.

## ✨ Features
- **Professional photo editing** — Retouch, correct, and composite images with layers, masks, and a wide range of adjustment controls.
- **Precise vector design** — Draw crisp, resolution-independent artwork with pen, node, and shape tools for logos, icons, and illustrations.
- **Page layout and publishing** — Arrange text, images, and graphics across multi-page documents ready for print or screen.
- **Unified workspace** — Move between photo, vector, and layout tasks within a consistent interface so your project stays in one flow.
- **High-performance canvas** — Work smoothly on large files and detailed artwork with a responsive, hardware-accelerated engine.
